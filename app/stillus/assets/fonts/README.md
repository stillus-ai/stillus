# Bundled Noto fonts

The unmodified font files come from
[notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf).
Their original SIL Open Font License is preserved in LICENSE; SHA256SUMS records
the exact bundled bytes. Fonts are loaded locally, without runtime downloads.

Noto Sans supplies regular, italic, semibold and semibold italic text with
Cyrillic support. Noto Sans Mono supplies editor/code text; Noto Serif supplies
semibold headings. Other scripts may use the native font system's glyph fallback.
